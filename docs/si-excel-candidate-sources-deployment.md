# Smart Inspection POC 2 — Excel Candidate Source Feeds (PR #55)

This replaces the ad-hoc source event form with **separate Excel-source intake
screens**, while NMC continues as a **live direct source**. The intent is
business-realistic, transparent source provenance — **not** to make uploaded
PSC/Service Excel records look official.

## Business flow / boundaries

| Candidate source | Entry | Authority | Result |
| --- | --- | --- | --- |
| NMC approved inspection referral | **LIVE** existing Oracle NMC Case Workspace | Official within this NMC POC | Remains human-approved NMC referral, marked MANDATORY |
| Maritime Service Requests | Excel `SERVICE_REQUESTS` | POC_SIMULATOR / UNVERIFIED | Inspection Candidate, MANUAL_REVIEW |
| PSC Port Call Notifications | Excel `PSC_PORT_CALLS` | POC_SIMULATOR / UNVERIFIED | Inspection Candidate, MANUAL_REVIEW |

A high NMC risk does not automatically create a candidate.
Distinct inspection regimes are not collapsed (one IMO can be referred for
a Service Inspection and a PSC Inspection separately). Existing NMC case
referrals are NEVER imported, modified, duplicated or overwritten by Excel.

**Screens (same MOEI header/footer, bilingual and RTL):**

- `/#/moei/smart-inspection/settings/sources` — Source registry with NMC
  live card, Service and PSC Excel import cards, recent import history.
- `/#/moei/smart-inspection/settings/sources/nmc` — read-only NMC source details.
- `/#/moei/smart-inspection/settings/sources/service-requests` — source template,
  file upload, preview, validation errors, explicit commit.
- `/#/moei/smart-inspection/settings/sources/psc-port-calls` — independent PSC
  Excel template/upload/preview/commit.
- `/#/moei/smart-inspection/candidates` — operational candidate queue now shows
  source counts, risk, evidence and Excel filename / batch / row. Ad-hoc
  single-event form is removed. Officer decision/approval unchanged.

Each Excel source screen offers **Download Template** generated by the same
backend that validates the source feed; the template includes a matching
active POC fleet IMO. Excel template contains a READ_ME tab and the exact
source-specific sheet / header row. Do not use an ERP workforce template
for candidate sources.

## Excel schema (headers MUST occupy row 1)

**SERVICE_REQUESTS** worksheet:
`request_id | request_reference | imo | port | request_date | service_type | notes`
(`request_date` format `YYYY-MM-DD`.)

**PSC_PORT_CALLS** worksheet:
`port_call_id | port_call_reference | imo | port | eta_local | visit_purpose | notes`
(`eta_local` format `YYYY-MM-DDTHH:mm`, Dubai local time.)

**NMC:** no Excel upload, never replaced by file. NMC Case Workspace is the
sole source for approved NMC referrals. The fleet source currently contains
420 POC vessels. Imported IMO must match a known active fleet IMO or the
relevant Excel row fails explicitly; no made-up vessel or official risk score.

## Validation/security

- Exact source-specific worksheet/row-1 headers, max **2 MB** / **1000 rows**,
  all mandatory fields, string literals only, no formulas, valid dates.
- Duplicate source-event ID within one workbook → row error.
- Existing identical events → counted as replays; no duplicate created.
- Existing event ID with altered business data → conflict; does NOT rewrite
  history or overwrite other source feeds.
- Preview is **read-only** and expires after 10 minutes. If ANY row errors,
  **the full file cannot be committed**; correct Excel and preview again.
- Editor permission for preview, status, commit; 3+ character business actor
  required for commit. File checksum, original source row, event ID, Excel row,
  batch, actor, and import timestamp are preserved in the *SI* event JSON.
- Each commit performs one atomic Oracle transaction (all rows or none) in
  existing `SI_CANDIDATE_EVENT`. JSON-mode POC stores one atomic snapshot.
- No Airia call on GET, preview or commit. No AI/risk/case automation from Excel.
- Legacy `POST /api/si/v1/candidates/source-events` returns
  `410 SI_SOURCE_EXCEL_IMPORT_REQUIRED` to prevent manual POC source injection.

### Oracle Data/Schema Migration

**NO NEW DATABASE MIGRATION REQUIRED IN THIS PR.**

New Excel records are stored in the **existing Oracle
`SI_CANDIDATE_EVENT` created by migration 009**. Batch/file/row metadata
is embedded in `DOC_JSON`, so there is no migration 011 and no DDL or
backfill. Existing NMC assessments, risk scores and case tables are untouched.

**Dependency check before import** (inside `oracle-free-23`):

```powershell
docker exec -it oracle-free-23 bash
```
Inside the container: `sqlplus -L /nolog`, then:
```sql
CONNECT NMC_AI@"localhost:1521/freepdb1"
SELECT USER, SYS_CONTEXT('USERENV','CON_NAME') AS PDB_NAME FROM DUAL;
SELECT TABLE_NAME FROM USER_TABLES
 WHERE TABLE_NAME IN ('SI_CANDIDATE_EVENT','SI_CANDIDATE_DECISION',
   'SI_INSPECTION_CASE','SI_TARGETING_RULE_VERSION')
 ORDER BY TABLE_NAME;
SELECT COUNT(*) AS EXISTING_SI_EVENTS FROM SI_CANDIDATE_EVENT;
SELECT COUNT(*) AS EXISTING_NMC_AI_SCORES FROM NMC_AI_ASSESSMENT;
EXIT
```
All four SI tables must exist; if not, apply **migration 009 once** according
to the parent PR #49 runbook **after verified backup**, NOT as part of this
UI/import fix. Oracle DDL autocommits; do not rerun any applied migration.

## User acceptance

1. Open `/#/moei/smart-inspection/settings/sources`, enter Editor key,
   press **Load Sources**.
2. NMC card must say **LIVE NMC** and display current approved referrals.
   No NMC Excel button exists.
3. Click Service Requests. Download its own XLSX Template. Preview it:
   see POC fleet IMO, row counts and **new/duplicate/error** totals.
4. Commit intentionally. Open `Candidate Center`; Service candidate appears
   for human review with Excel filename, batch and source row.
5. Repeat for PSC with a different source template; PSC Candidate appears
   under PORT_STATE_CONTROL — even when the IMO matches a Service Candidate.
6. Re-upload same file: replayed events count increases, **no duplicates**
   created. Change existing event's port but keep source ID: preview FAILS.
7. Import a non-fleet IMO, formula or wrong-source workbook: entire preview
   fails and **no row** persists to Oracle.
8. Restart `ai-proxy` (keep volumes), re-open status: old imported records and
   source lineage remain, with NMC referrals unchanged.
9. Only supervisor-approved officer decisions create SI cases; imported
   records stay UNVERIFIED/MANUAL_REVIEW until manually processed.
10. Switch العربية/English: white menu, footer and import screens stay part
    of the unified MOEI theme.

on the target deployment.
