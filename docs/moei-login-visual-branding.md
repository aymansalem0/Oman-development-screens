# MOEI login visual identity – cinematic harbor + official Ministry logo

This visual-only enhancement is **stacked on Google SSO PR #89** and must not be merged independently.

## Identity and artwork
- The ministry's official bilingual wordmarks are **reused unchanged** from the project's existing `public/branding/uae-moei-{en,ar}.png` assets using its `NmcMinistryLogoComponent` on **both the left maritime background area and the login card**. Do not regenerate or stylize the official logo.
- A new independently designed platform icon `public/branding/moei-maritime-platform-mark.svg` expresses ship bow + compass + digital routes + ocean wave. It replaces the old anchor/helm icon in the Login and unified NMC/SI sidebar without impersonating an official ministry logo.
- A self-contained procedural harbor illustration `public/branding/moei-login-maritime.svg` is the guaranteed default background.
- A higher quality **AI-created photorealistic login backdrop** is available as optional project artwork under `public/branding/moei-login-maritime.avif`. It is not part of this text-only GitHub branch due to binary upload constraints. Add it with the downloadable **moei-login-photo-assets.zip** delivered in the chat (extract directly into repository root). The CSS gracefully falls back to the committed SVG whenever this optional file is absent.

## Layout
Desktop: left artwork/brand/story with official ministry logo, right accessible sign-in panel featuring ministry logo and custom platform identity. Mobile: image-backed centered login card.
All existing OIDC callbacks, Google authorization checks, approved-account allowlist, ADMIN user management, legacy optional local-mode form and Angular route guards are unchanged.

## Local deployment
Use only on the correct branch:
```powershell
git fetch origin
git switch --track origin/feature/moei-login-visual-branding-20261013
# Download moei-login-photo-assets.zip from the ChatGPT reply and extract from your Downloads directory:
Expand-Archive -Path "$env:USERPROFILE\Downloads\moei-login-photo-assets.zip" -DestinationPath "." -Force
# Keep your existing .env with OAuth credentials untouched.
$dc=@('-f','compose.yaml','-f','compose.google-psc.yaml','-f','compose.oracle.yaml','-f','compose.incident-google.yaml')
docker compose @dc config --quiet
docker compose @dc build nmc
docker compose @dc up -d --no-deps --no-build --force-recreate nmc
```
Open `http://localhost:4200/#/moei/login`.
Run `npm run build` and `node --test scripts/test-moei-admin-login-ui.mjs`.

### Key scope note
The optional AVIF photograph is decorative. Any official ministry mark always appears as the original institutional artwork overlaid by Angular, never inside/generated by the AI image itself. Approval of branding for formal ministry production deployment remains required.
